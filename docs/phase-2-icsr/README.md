## Purpose

Phase 2 of this project focuses on **how organizations achieve COSO-aligned Internal Control over Sustainability Reporting (ICSR) in practice**.

While Phase 1 explores foundational questions about sustainability data and systems, Phase 2 examines implementation, governance, and operationalization.

---

## Scope of Phase 2 questions

Phase 2 questions may address topics such as:

- Designing and testing ICSR controls
- Integrating ICSR with internal audit
- Managing control deficiencies in sustainability reporting
- Applying segregation of duties in sustainability data pipelines
- Monitoring models, assumptions, and scenarios
- Aligning ICSR across multiple assurance regimes

---

## Who should contribute

Contributions are especially encouraged from:

- External auditors
- Internal audit professionals
- Sustainability and finance practitioners
- Regulators and standard setters
- System architects and data engineers

---

## How Phase 2 differs from Phase 1

Phase 2 questions are:
- More operational
- More control-focused
- Closer to practice
- Still exploratory (not prescriptive)

They are intended to **surface implementation challenges**, not define mandatory solutions.

---

## How to contribute

Use GitHub Issues to propose new Phase 2 questions, reference existing Phase 1 questions, and share perspectives grounded in practice.
